# eskiNess на Android — как собрать APK

Игра уже готова к экспорту: в папке есть пресет **Android** (`export_presets.cfg`),
мобильный рендер и экранное управление. Нужно один раз подготовить компьютер, потом
собирать в пару кликов.

## 1. Что поставить (один раз)

1. **Godot 4.7.2** — тот же, которым открываешь игру.
2. **Шаблоны экспорта** для 4.7.2.
   В Godot: `Редактор → Управление шаблонами экспорта… → Загрузить и установить`.
   Если не качается, скачай `Godot_v4.7.2-stable_export_templates.tpz` с godotengine.org
   и выбери его там же через `Установить из файла`.
   Если Godot стоит через scoop, шаблоны лежат в
   `C:\Users\<ты>\scoop\apps\godot\current\editor_data\export_templates\4.7.2.stable\`:
   там должны быть `android_debug.apk` и `android_release.apk`.
   Шаблоны от 4.4 и 4.6 не подходят, версия должна совпадать.
3. **JDK 17**, например Eclipse Temurin 17: <https://adoptium.net/temurin/releases/?version=17>.
   Ставь в папку по умолчанию, обычно `C:\Program Files\Eclipse Adoptium\jdk-17...`.
4. **Android SDK, минимальный набор.** Android Studio целиком не нужна.
   - Скачай **Command line tools only** для Windows: <https://developer.android.com/studio#command-tools>.
   - Создай папку `C:\Android\Sdk\cmdline-tools\latest` и распакуй туда архив так,
     чтобы получилось `C:\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat`.
   - Открой PowerShell и выполни:
     ```
     $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.13.11-hotspot"   # свой путь к JDK
     cd C:\Android\Sdk\cmdline-tools\latest\bin
     .\sdkmanager.bat --licenses
     .\sdkmanager.bat "platform-tools" "build-tools;35.0.1" "platforms;android-35"
     ```
     На каждый вопрос про лицензии отвечай `y`.
     Если пишет `Could not determine SDK root`, добавь в обе команды `--sdk_root=C:\Android\Sdk`,
     например `.\sdkmanager.bat --sdk_root=C:\Android\Sdk --licenses`.
     Если Godot потом попросит другую версию build-tools, поставь её той же командой.

## 2. Указать пути в Godot (один раз)

`Редактор → Настройки редактора → Экспорт → Android`:

- **Java SDK Path** — папка JDK 17, например `C:\Program Files\Eclipse Adoptium\jdk-17.0.13.11-hotspot`.
- **Android SDK Path** — `C:\Android\Sdk`.
- **Debug Keystore** — смотри следующий шаг.

## 3. Debug keystore (ключ для отладочной подписи)

Обычно Godot создаёт его сам, когда указан путь к JDK: поле **Debug Keystore**
заполняется автоматически, логин `androiddebugkey`, пароль `android`.

Если поле осталось пустым, создай ключ вручную в PowerShell:

```
& "C:\Program Files\Eclipse Adoptium\jdk-17.0.13.11-hotspot\bin\keytool.exe" -genkeypair -v -keystore C:\Android\debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US" -deststoretype pkcs12
```

Затем в настройках укажи:

- **Debug Keystore**: `C:\Android\debug.keystore`;
- **Debug Keystore User**: `androiddebugkey`;
- **Debug Keystore Pass**: `android`.

⚠️ Ключи и пароли **не коммить** в репозиторий, он публичный.
Они хранятся в настройках редактора, а не в папке игры, и это правильно.

## 4. Собрать APK

1. Открой проект игры в Godot.
2. `Проект → Экспорт…` и слева выбери пресет **Android**.
   Проверь в пресете: **Architectures** — включена только `arm64-v8a`
   (`armeabi-v7a` выключена), **Min SDK** и **Target SDK** пустые (Godot подставит свои).
3. Если внизу красный текст, там написано, чего не хватает (шаблонов, SDK, ключа).
   Исправь по шагам выше.
4. Нажми **Экспортировать проект…**, оставь галочку **Экспорт в режиме отладки**
   и сохрани. По умолчанию файл уже указан: `godot/eskiNess.apk`. Файлы `.apk` в git не попадают.

### Или одной командой (без открытия редактора)

Из папки репозитория, когда шаблоны и SDK уже настроены:

```
godot --headless --path godot/THE LEAK --export-debug "Android" ../eskiNess.apk
```

Если чего-то не хватает, команда так и напишет, например, путь к отсутствующему `android_debug.apk`.

## 5. Поставить на телефон

Способ А, проще всего:

1. Скинь `eskiNess.apk` на телефон через кабель, Telegram или облако.
2. Открой файл на телефоне и разреши «установку из неизвестных источников», когда спросит.

Способ Б, по кабелю одной кнопкой:

1. На телефоне: `Настройки → О телефоне`, 7 раз нажми на «Номер сборки».
   Потом `Для разработчиков → Отладка по USB`.
2. Подключи телефон кабелем и разреши отладку на экране телефона.
3. В Godot справа вверху появится значок Android. Нажми его, и игра поставится
   и запустится сама.
4. Можно и командой из папки репозитория: `C:\Android\Sdk\platform-tools\adb.exe install -r godot\eskiNess.apk`.

## 6. Если игра вылетает — снять лог

Сначала `git pull`, пересобери APK и поставь заново. Версия в пресете растёт
(сейчас 0.3), поэтому новый APK ставится поверх старого.

Если всё равно вылетает:

1. Включи на телефоне «Отладку по USB» (шаг 5, способ Б) и подключи кабелем.
2. В PowerShell:
   ```
   cd C:\Android\Sdk\platform-tools
   .\adb.exe logcat -c
   ```
3. Запусти игру на телефоне и дождись вылета.
4. Сразу после вылета:
   ```
   .\adb.exe logcat -d > $HOME\Desktop\log.txt
   ```
   или короче, только ошибки и сообщения Godot:
   ```
   .\adb.exe logcat -d *:E godot:V > $HOME\Desktop\log.txt
   ```
5. Пришли `log.txt` с рабочего стола или скрин последних строк.
   Самое важное — строки со словами `godot`, `FATAL`, `SIGSEGV`, `ERROR`.

## Управление на телефоне

Кнопки появляются только на телефоне. На ПК всё по-старому: клавиатура и мышь.

**В игре:**

| Что | Как на телефоне | На ПК было |
|---|---|---|
| Ходьба | джойстик слева (ставь палец в любое место левой части экрана) | WASD |
| Бег | джойстик до упора вперёд | Shift |
| Обзор | водить пальцем по правой части экрана | мышь |
| Прыжок | ПРЫЖОК | пробел |
| Стойка (поднять/опустить кулаки) | СТОЙКА | ПКМ |
| Удар | УДАР (если кулаки опущены — сначала поднимет) | ЛКМ |
| Взаимодействие: автомат KILLBOX, ящики, сейф, магазин, лоток автомата (смотреть на него) | E | E |
| Подобрать вещь с пола | просто наступить на неё или подойти вплотную; издалека (до 3 м) — навести центр экрана и нажать E | так же |
| Фонарик | СВЕТ | F |
| Противогаз | МАСКА | G |
| Лечение | ЛЕЧИТЬ | Q |
| Хотбар | нажать на ячейку 1–5 внизу экрана | 1–5 |
| Инвентарь | СУМКА (справа вверху) | Tab / I |
| Пауза | II (правый верхний угол) | Esc |

Можно жать одновременно: идти джойстиком, смотреть другим пальцем и бить.

**В инвентаре:**

- коснуться предмета — использовать или надеть, по надетому — снять;
- **подержать палец** на предмете полсекунды — окно «сколько выбросить»; надетое при удержании снимается на пол;
- перетащить пальцем — переложить в другую ячейку или в слот на силуэте; за окно — выбросить;
- привязать к хотбару: коснуться предмета, потом ячейки 1–5 внизу экрана;
- «Выбросить монеты», «Скрафтить» — обычные кнопки;
- закрыть — СУМКА или крестик в правом верхнем углу.

**Окна лута (сундук, кувшин, сейф):** коснуться предмета — взять, кнопка «Забрать всё (R)» — всё сразу,
«Закрыть» или крестик — закрыть. Не взятое высыпается на пол и само не подбирается,
пока не отойдёшь и не вернёшься.

**Магазин, меню, настройки:** обычные кнопки и ползунки, нажимаются пальцем.
Список товаров прокручивается свайпом. Магазин закрывается кнопкой «Закрыть» или крестиком.
В окне продажи касание перекладывает всю стопку. Продать одну штуку из стопки на телефоне
пока нельзя: на ПК это Shift+клик.

**Настройки на телефоне:** страницы «Управление» нет, клавиши не переназначаются.
Её заменяют экранные кнопки. При первом запуске графика ставится на «низкую».
Поднять можно в `Настройки → Графика`.

## Что проверить на телефоне после сборки

1. Запуск: доходит до меню, не вылетает после логотипа.
2. Настройки: всё влезает, внизу видны кнопки «Графика / По умолчанию / Назад», графика «низкая».
3. В игре: джойстик, обзор пальцем, УДАР, СТОЙКА, ПРЫЖОК, ПРИСЕД, E, СВЕТ, МАСКА, ЛЕЧИТЬ, СУМКА, пауза.
4. Подбор: наступить на вещь — подбирается; издалека — E.
5. Инвентарь: слоты «Лицо» и «Спина» видны. Касание — использовать, удержание — выбросить,
   перетаскивание работает.
6. Кувшин или сундук: окно лута, «Забрать всё», крестик.
7. Магазин: вкладки, прокрутка свайпом, покупка, окно продажи, закрытие.
8. Автомат KILLBOX: окно круток, крутка, сбор монет из лотка (E, глядя на лоток).
9. Наверху: Нюхич (МАСКА), враги — тяжёлый и быстрый «Шныга». Следи за FPS.
10. Пауза → «Выход в меню» → снова в игру (сохранение).

## Что ещё по-другому на телефоне

- **Графика.** На телефоне рендер Compatibility (OpenGL ES 3): он работает почти на всех телефонах,
  а Vulkan часто вылетает сразу после логотипа. На ПК по-прежнему Forward+, картинка как была.
  На телефоне нет SSAO, отражений, объёмного тумана, декалей и теней от потолочных ламп.
  На стенах меньше сколов, в воздухе меньше пыли: так быстрее загрузка и выше FPS.
- **Размер интерфейса** подстраивается под экран: на вытянутых телефонах (20:9) всё крупнее,
  на планшетах (4:3) окна всё равно влезают.
- **Проверить кнопки на ПК** можно запуском с флагом `--touch`:
  `godot --path godot/THE LEAK -- --touch`. Мышью кнопки не нажимаются, нужен сенсорный экран.
- **Чувствительность обзора** — `LOOK_K` в `touch_controls.gd`. Больше число — быстрее поворот.
- **Права приложения** не нужны: игра не ходит в интернет.

Версию для нового APK меняй в `Проект → Экспорт → Android → Version → Code`
(просто +1), иначе телефон может не захотеть ставить поверх старой. Сейчас Code 3, версия 0.3.
