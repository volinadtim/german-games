# Игры Германа 🎮

Репозиторий со всеми играми, которые делает Герман.

## Структура

| Папка | Что там |
|---|---|
| `godot/<игра>/` | Игры на **Godot 4** (GDScript). Открывать `project.godot` в Godot. |
| `rust/<игра>/` | Игры на **Rust** (общий Cargo workspace в корне). Запуск: `cargo run -p <игра>` |
| `test-game/` | Первые эксперименты (HTML) |
| `scripts/` | Служебные скрипты (автообновление и т.п.) |

## Автообновление на другом компьютере

Нужен только [Git for Windows](https://git-scm.com/download/win).

1. Скачать [`scripts/auto-pull.bat`](scripts/auto-pull.bat) и [`scripts/auto-pull.ps1`](scripts/auto-pull.ps1) в любую папку (например `C:\games-sync\`). Дальше лучше запускать уже из клона: `%USERPROFILE%\german-games\scripts\auto-pull.bat` — так скрипт сам обновляется.
2. Дважды кликнуть `auto-pull.bat`.
3. Скрипт сам склонирует репозиторий в `%USERPROFILE%\german-games` и каждые 10 секунд будет подтягивать свежие изменения. Окно не закрывать.

Свою папку/интервал можно задать: `auto-pull.bat D:\games 5`.

Если на том компьютере что-то поменяли руками (например Godot пересохранил файл), скрипт уберёт эти изменения в `git stash` и всё равно обновится — ничего не теряется, вернуть можно через `git stash pop`.
