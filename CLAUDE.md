# Правила работы в этом репозитории

Репозиторий для всех игр Германа. Публичный: https://github.com/volinadtim/german-games

## Процесс (обязательно)

1. **Оптимистичный поток.** После реализации задачи — сразу `git add` + `git commit` + `git push` в `main`. Без предварительных тестов и проверок, без веток и PR.
2. **Проверка после пуша.** Сразу после пуша проверяем результат (запуск/импорт в Godot, `cargo check`/`cargo run`, просмотр кода). Нашли проблему — чиним и снова сразу коммит + пуш.
3. Пользователь параллельно смотрит результат на другом компьютере (там работает `scripts/auto-pull.ps1`), поэтому пушить надо часто и маленькими шагами.
4. Коммиты — короткие, по-русски или по-английски, описывают что сделано.

## Стек

- **Godot 4** (GDScript) — игры в `godot/<игра>/`, у каждой свой `project.godot`.
  - Не коммитить `.godot/` (кэш). Файлы `*.import` и `*.uid` — коммитить.
- **Rust** — игры в `rust/<игра>/`, общий workspace в корневом `Cargo.toml` (`members = ["rust/*"]`).
  - Новая игра: `cargo new rust/<игра>`; запуск `cargo run -p <игра>`.
  - Для графики по умолчанию `macroquad` (простой), для крупных — `bevy`.

## Окружение

- Windows. Имена папок игр — `kebab-case`, латиницей.
